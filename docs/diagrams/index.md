# Diagramas de arquitectura y flujos

Los diagramas HTML se compilan a partir de especificaciones JSON con Archify. Son autocontenidos y se pueden abrir en una pestaña independiente.

| Vista | Diagrama | Especificación |
|---|---|---|
| Arquitectura full-stack | [Abrir arquitectura](architecture.html) | [`architecture.json`](architecture.json) |
| Secuencia del cargue de personal | [Abrir secuencia](sequence_main.html) | [`sequence_main.json`](sequence_main.json) |
| Decisiones del procesamiento batch | [Abrir workflow](workflow_main.html) | [`workflow_main.json`](workflow_main.json) |

Los flujos de segundo nivel se agregan como diagramas separados para mantener legible cada vista.

El contenido de los diagramas está en español. Los controles fijos del visor Archify pueden aparecer en inglés porque el visor no ofrece una localización española.
